# HR-Analytics-Dashboard

An interactive **HR Analytics Dashboard** built using **Microsoft Power BI** to analyze employee data and understand employee attrition patterns.

## Dashboard Preview

![HR Analytics Dashboard](dashboard.png)

## Tools Used

* Microsoft Power BI
* Power Query
* DAX

## Skills

* Data Cleaning & Transformation
* Data Analysis
* Data Visualization
* Data Modeling
* DAX
* Dashboard Development

## Project Overview

This project focuses on analyzing employee data to understand **employee attrition and workforce patterns**.

The dashboard provides analysis based on:

* Employee Attrition
* Age Group
* Education Field
* Job Role
* Salary Slab
* Years at Company
* Gender

## Insights

* Total Employees: **1.47K**
* Total Attrition: **237**
* Attrition Rate: **16.1%**
* Average Age: **37 years**
* Average Monthly Income: **6.50K**
* Average Years at Company: **7 years**
* The **26–35 age group** has the highest attrition.
* **Laboratory Technicians** have the highest attrition among the displayed job roles.
* Employees with a salary of **up to 5K** show the highest attrition.
* Attrition is also analyzed across **education fields, gender, job roles, and years at company**.

## Objective

The objective of this project is to analyze HR data and identify employee attrition patterns using **Power BI and data visualization**.
